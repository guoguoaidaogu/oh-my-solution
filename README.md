# oh-my-solution

# [立即访问](http://oms.shertist.fun/archive/%E7%94%A8%E6%88%B7:Solution.html)

本仓库归档了[（旧版）香蕉空间](https://bananaspace.org/legacy/)上 The Legacy of FDUer 的内容，快照时间为 2026 年 10 月 13 日下午。

The Legacy of FDUer 中的所有页面均收录于本仓库 `archive` 目录，并保持原有文件结构，既包括原始最终版本的 `bTeX` 文件 `*.btx`，也包括在本地编译生成的“纯净版” `html` 文件。

受时间与能力所限，这里仅保存了静态的最终版本，未能一并备份各页面创建与修改的历史记录。在此向每一位贡献者致以诚挚歉意。

本仓库仅供过渡时期学习交流使用；如有侵权，请联系删除。
