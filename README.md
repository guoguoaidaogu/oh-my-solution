[The Legacy of FDUer](https://bananaspace.org/legacy/wiki/%E7%94%A8%E6%88%B7:Solution) 内的所有页面在本仓库 `archive` 目录下按原文件结构给出，包括原始的最终版本 `bTeX` 文件 `**.btx` 和在本地编译得到的“纯净版” `html` 文件。

因时间和能力有限，仅储存了静态的最终版本，未能一并备份各页面创建和修改的历史记录。在此对每一位贡献者表示深刻歉意。

仅供过渡时期学习交流使用。如有侵权请联系删除。
